| 账号 | 角色 | 说明 |
| --- | --- | --- |

## 二、用例

| # | 步骤 | 预期 |
| --- | --- | --- |
| 1.1 | 用 `2021001`/`123456` 登录 | 进入首页，右上角显示「张三」，通知角标为 2 |

## 三、已发现并修复的问题（回归记录）

| 问题 | 根因 | 修复 |
| --- | --- | --- |
| 点击通知已读后卡片样式不更新 | Vue 3.5 中 reactive 数组读方法（find 等）返回 raw 元素，改其属性不触发渲染 | 用索引整体替换元素 `list[idx] = { ...list[idx], isRead: true }` |
| 匹配页对方物品只显示「物品 #4」 | 接口仅返回 lostItemId/foundItemId | 前端批量补拉对方物品的标题/描述 |

## 四、契约待确认项（已提请在 PR 描述中与后端 C 确认）

1. 列表分页返回形态：代码已兼容 `{list,total}` / `{records,total}` / 纯数组三种，建议后端固定为 `{list,total}`。
2. 分类/地点无公共查询接口：发布页暂用与 `database/seed.sql` 一致的固定值，后端补充接口后替换。
3. 认领审核与交接：契约中 `POST /claims/{id}/approve` 与 `POST /handovers` 并存，README 又提到 approve 事务内创建交接。当前实现按「两步独立操作」处理，请后端确认实际行为。
4. 物品图片上传：`docs/api.md` 暂无上传接口，发布页目前仅本地预览、不实际上传，联调时需补充。
